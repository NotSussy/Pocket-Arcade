Help installing

Windows: open the file. If it says “Windows protected your PC,” click More info, then Run anyway.

Mac: unzip it, drag Pocket Arcade to Applications, then right-click → Open the first time. If it says it’s damaged, open Terminal and run xattr -cr "/Applications/Pocket Arcade.app".

Android / Pixel: open the downloaded .apk. When Android asks, allow installing from your browser, then tap Install. (Pixels use the same file as other Android phones.)

No download needed: in Chrome or Edge, open the website’s menu and choose Install app (or Add to Home screen). On iPhone, use Safari’s Share button → Add to Home Screen.

The apps open the arcade website, so they update themselves. They’re not from an app store, so your device may show a warning first.
